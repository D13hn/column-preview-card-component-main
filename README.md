✨ **What I learned**

This challenge was a wonderful opportunity to troubleshoot and refine my layout skills. Here is what I focused on:

- **Layout Structure:** Using CSS Flexbox effectively to align and center cards properly across different viewport sizes.
- **Responsive Design:** Implementing Media Queries and adjusting container max-widths and padding to ensure the layout transitions smoothly from desktop rows to a mobile single-column layout without overflow issues.
- **Problem Solving:** Overcoming sizing and alignment challenges by switching to flexible units and adjusting body height constraints (`min-height: 100vh`) to prevent content overlap on smaller screens.
